# Load the method by task

Choose the scenario by what the audience gains, then read the one row your current task needs. Styles and scenarios can be crossed; state the reason for the fit and re-check facts, assets, reading and capability.

| Scenario | What the audience gains and main method |
| --- | --- |
| product-demo | Understand a real task, the operation and the result; read [product expression](product-expression.md) |
| knowledge-explainer | Understand a concept, its relations and its process; read [object is explanation](knowledge-visualization.md), [domain standards](domain-standards.md), [layered reveal](layered-reveal.md) and [knowledge pack](knowledge-pack.md) |
| news-brief | Separate event, source, date, change and unknown; reuse the knowledge pack, and additionally check recency and factual footage |
| image-story | Build order and emphasis from the given images; read [asset performance and routing](asset-motion-direction.md), and preserve the subject and crop safety |
| story-video | Keep people, events and turns continuous; read [shot production planning](shot-production.md) |
| feature-motion | Show initial state, trigger, change and end state; read [visual emphasis](visual-emphasis.md) and [product expression](product-expression.md) |
| brand-film | Establish brand feeling and visual memory; use [creative direction](creative-direction.md) to separate fact, vision and symbol |
| music-visual | Organise the experience with sections, motifs, variation and release; read [music direction](music-direction.md) and [sound and rhythm](sound-and-rhythm.md) |

## Read further by stated intent

| User intent or production condition | Route and constraints |
| --- | --- |
| A concept, principle or mechanism needs music to carry it | knowledge-music-explainer; read [concept knowledge explainer arrangement](knowledge-music-direction.md), and derive the knowledge layers and shots from the actual structure of the chosen track first |
| Explaining knowledge, history, mechanism, industry or social issues through rap/hip-hop | select knowledge-rap-explainer automatically; read [rap explainer](knowledge-rap-direction.md). A background-music request does not automatically switch to rap; choose the recipe for product promotion by its main goal |
| Product promotion needs lyrics, sections that organise the motion, or chorus variation | product-music-story; read [product music story](product-music-story.md), and check the task and the lyric claims first |
| Feed-style explainer or promotion | read [opening design](opening-design.md) by default; check the first frame, the first three seconds, the sound handoff and whether the body delivers |
| 30-second launch film, several features chained into chapters | read [launch film grammar](launch-film-grammar.md); choose launch-film-arc or feature-chapter-reel as needed; a short single-feature film takes only the parts that fit |
| Character performance, cinematic camera moves, space, light reflection or cross-engine assembly | read [scene and tool composition](scene-tool-composition.md); write expression, pose, movement and end state first, then build the scene |
| Character, motion, prop, environment or sound assets | read [production tool contract](production-tool-contract.md); use the project cache and licensed library first, fill the gaps after; compare HDRI against the same shot, and split Japanese voiceover from BGM |
| Interface emphasis, explaining an operation, dynamic callouts | read [visual emphasis](visual-emphasis.md); define the target and the protected area, and check camera mapping, label following and occlusion |
| Voiceover, the user's own voice or a character narrating | read [explainer narration](explainer-narration.md); get a clear script and approved references first, then obtain real audio; never force on-camera presence or auto-switch to a paid service |
| Finding, generating, combining or layering assets | read [asset selection](asset-routing.md); for independent movement, reassembly and cross-shot handoff also read [asset routing](asset-motion-direction.md) |
| Studying reference films and the creative process | read [reference film study](reference-film-study.md); keep the mapping between instructions, versions, failures and outputs, and separate observation, measurement, inference and anything not yet auditioned |
| Combining local expression and motion | read [expression composition](expression-method.md); use motion, relations, constraints, recipes and production rules separately — looking up an entry is not the same as invoking an effect |

Recipe music configuration is read at run time: user choice → project selection → current recipe default. A single selection does not change the candidate pool; configuration changes only after the user explicitly adds a candidate or sets a default. Changing the track re-measures the timing, and a missing source is never replaced silently. Full rules in [music direction](music-direction.md).
